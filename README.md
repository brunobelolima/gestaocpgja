# IAC-Pal v1.2 — Fluxo Interativo

Arquivo principal: `index.html`

Funcionalidades:
- 10 domínios avaliados progressivamente, um por vez.
- cálculo automático do escore total (0–30);
- estratificação baixa / moderada / alta;
- marcadores de alerta;
- eixos M (médico), E (enfermagem) e A (acesso/modalidade);
- sugestão de Consultório, N1, N2A, N2B, N3 ou plano individualizado;
- valores e composição assistencial atualizados;
- regra de segurança para domínios com escore 3.

Observação:
O IAC-Pal é instrumento clínico-operacional em desenvolvimento e não possui validação psicométrica. A saída não substitui julgamento clínico.
